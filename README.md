# 獵光者未來俱樂部

一、網站主題與目標受眾：

網站主題：

　一家位於台北市，提供高品質咖啡與貓咪互動的貓咪咖啡廳「貓癒所」。

目標受眾：

　喜歡貓咪的年輕人、情侶、以及需要放鬆療癒空間的上班族。

二、網站核心功能與特色：

核心功能：

　1. 可愛貓咪介紹：展示店內每一隻貓咪的照片、名字和個性。

　2. 線上預約系統：讓顧客可以預約來店時段。

　3. 餐點菜單：展示店內提供的咖啡、茶飲及點心。

　4. 消費方式說明：清楚告知入場費用及規定。

　5. 訪客須知與 Q&A：提供與貓咪互動的注意事項。

網站風格與特色：

　溫暖、療癒、可愛，使用大量貓咪的可愛照片，色調以木質調和暖色系為主。

三、網站內容與文案：

首頁標題：

　歡迎來到「貓癒所」，一個讓你被貓咪療癒的溫暖角落。

關於我們：

　「貓癒所」不僅是一家咖啡廳，更是人與貓咪建立深刻連結的橋樑。

　我們致力於提供一個舒適、乾淨的環境，讓每一位客人都能在這裡找到片刻的寧靜與快樂。

貓咪成員：

　拿鐵：店裡的撒嬌大王，最喜歡被摸下巴。

　布丁：好奇心旺盛的探險家，總在追逐雷射筆。

聯絡方式：

　地址：台北市 XX 區 XX 路 XX 號

　電話：02-1234-5678

　營業時間：週二至週日 11:00 - 21:00（週一公休）

四、參考網站：

　https://www.nekorepublic.jp/（日本一家知名的貓咪中途咖啡廳）
